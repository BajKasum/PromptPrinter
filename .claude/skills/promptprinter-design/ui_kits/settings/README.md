# App — Settings

The Settings workspace: profile + workspace-plan cards, a **live** appearance switch (toggles this kit's own `.dark` class — a real demonstration of the token system), usage meters, API-key rows, the default-tools picker grid (built on ToolLogo/TOOL_VISUAL), security, danger zone, and the sticky "unsaved changes" save bar.

Source: `src/components/app/settings-workspace.tsx`, `theme-preference.tsx`, `tool-picker.tsx`.

Composes: Input, Label, Button, PlanBadge, UsageMeter, ToolLogo, Icon.
