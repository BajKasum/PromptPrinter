# App — Dashboard

The logged-in app shell: collapsible sidebar (real width/rail animation, Chat/Projekt tab switcher, account row), a ⌘K-style command palette, and the two main "rooms" (Chats list, Projekte grid) with an AppHeader-style greeting.

Source: `src/components/app/sidebar.tsx`, `command-palette.tsx`, `app-header.tsx`, `src/app/(app)/layout.tsx`.

Composes: Button, Logo, LogoMark, AnimatedMascot, Icon, PlanBadge, Input.
