# Auth — Login / Signup

Two-column auth shell: Finn's half (big animated mascot, floaters, one line in his voice) + the form half (OAuth first, then email/password), with a working login/signup switch and the full-screen SuccessCelebration overlay on submit.

Source: `src/components/auth/auth-experience-shell.tsx`, `sign-in-experience.tsx`, `oauth-buttons.tsx`.

Composes: Logo, AnimatedMascot, Floaters, Input, PasswordInput, Label, Button, SuccessCelebration, Icon.
